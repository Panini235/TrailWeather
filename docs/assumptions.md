# 假设与默认值（工程默认，非用户确认项）

编号规则：A-xxx。推翻任何假设需在 agent/decisions.md 记录。

- **A-001 时间选择器的时区解释**：详情页日期/时刻选择按**设备本地时区**解释，
  并同时显示对应 UTC 时刻。线路当地时区仅在地理编码结果携带时展示（geocoding 的
  IANA 时区字段），不用于解释输入。理由：无可靠的离线坐标→时区映射，不做虚假精确。
- **A-002 采样默认值**：间距 1.5 km、每条线路每来源 ≤24 节点（低耗电模式 3 km/12）。
  近似网格去重粒度 0.1°。均为可配工程参数，且 UI 注明“采样密度≠天气空间精度”。
- **A-003 行程模式基于最长连续段**：多段线路（OSM 关系/多 trkseg）的 ETA 与沿途天气
  基于最长连续段计算并在 UI 标注；总里程仍按全部段求和展示。
- **A-004 休息分摊**：总休息时长按距离比例分摊到 ETA，而非指定休息点。
- **A-005 缓存 TTL**：Open-Meteo 30 min、MET 20 min、Overpass 区域结果 10 min、
  stale 窗口 6 h。依据来源更新节奏的保守值，非官方规定。
- **A-006 演示线路**：assets 中 3 条 GPX 为真实地理区域的走向示意（含演示海拔），
  永久标注“演示”。不用于任何真实导航。
- **A-007 平台目录生成**：android/ios 模板不进仓库，构建前 `flutter create` 生成；
  定制文件（AndroidManifest/Info.plist/web/）提交。本地开发同样先跑 create。
- **A-008 国际化**：首版中文硬编码集中管理（lib/ui/strings.dart），ARB 迁移列为任务
  而非首发范围；架构上已预留（集中常量 + MaterialApp supportedLocales）。
- **A-009 无后端**：全部直连公开 API；不保存任何用户数据到服务端。
- **A-010 Web 端 MET Norway**：受浏览器 User-Agent 限制，标记为可能失败而非屏蔽，
  失败时 UI 如实显示来源错误。
- **A-011 收藏即持久化**：OSM 发现的线路加入收藏后存本机 JSON；会话内未收藏的
  OSM 线路在 App 重启后需重新“搜索此区域”获取（缓存 10 分钟内直接命中）。
- **A-012 详情页刷新**：详情页数据随查询参数（来源/模式/时间/配速）自动重新获取；
  显式“下拉刷新”未做（v1 用参数变更与重进页面触发）。
