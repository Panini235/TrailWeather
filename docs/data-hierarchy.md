# 数据层级：哪些是重点，哪些不是（D-035）

山晴面对的问题是“这条线、这个出发时间、走到那里时的天气”。所以一个指标是否重要，看它会不会改变两件事：

1. **决策**：去不去、怎么走、何时折返；
2. **准备**：穿什么、带什么。

不改变这两件事的指标只做参考。层级决定“怎么展示”，不决定“展示与否”：重点数据缺失时也要写“此来源未提供”（缺失 ≠ 安全）。

## 三层

| 层级 | 指标 | 展示 |
| --- | --- | --- |
| **决策** | 气温 / 体感、降水量 + 降水概率（分开）、阵风、能见度；以及天气现象（雷暴、雾、降雪）和日落 | 结论卡、山脊天气带、地图节点颜色、节点详情的 4 个大字；缺失写“未提供” |
| **准备** | 紫外线、低云、0℃ 层、降雪 / 积雪、湿度、风向 | 平时收在“更多指标”的“准备”组；触发阈值时升为节点详情里的信号标签，并进入穿衣建议 |
| **参考** | 持续风速、气压、总云量、中云、高云、露点、晴空紫外线、对流潜势、降雪占比、模型 / 网格 / 授权等溯源 | 只在“更多指标”的“参考”组出现，缺失时不占格子 |

代码：`lib/data/weather/wx_importance.dart`（`tierOf`、`signalsFor`），有单元测试。

## 准备层什么时候升为重点

| 信号 | 条件 | 依据 |
| --- | --- | --- |
| 紫外线高 / 很高 | 紫外线预报 ≥ 6（≥ 8 为警示） | 世界卫生组织分级 |
| 晴空紫外线可达 | 来源只有晴空值且 ≥ 6 | 只说“若放晴可达”，不当预报 |
| 雪面反光 | 有积雪或降雪，且紫外线 ≥ 2 | 新雪反射约 80%（世界卫生组织） |
| 高于 0℃ 层 | 节点海拔 ≥ 模型 0℃ 层 | 可能结冰或降雪 |
| 降雪 / 积雪 | 单小时新增 ≥ 0.5 cm / 模式积雪 ≥ 5 cm | 积雪为模型估计 |
| 低云 | 低云量 ≥ 80% | 山脊可能在云雾中 |
| 湿冷 | 气温 ≤ 5 ℃ 且湿度 ≥ 90% | 体感更冷，衣物受潮 |
| 对流潜势 | CAPE ≥ 1000 J/kg | 潜势，不是雷暴预报 |

## 把数据“结合起来看”

- **节点气象时间图**：同一时间轴上叠放高 / 中 / 低云、气温与体感、降水量（柱）与降水概率（底色）、风向（颜色按阵风）、紫外线、夜色和到达时刻。
  文字只有选中小时的一行数值。
- **穿衣建议（洋葱法）**：把体感、阵风、降水、紫外线、积雪、日出日落合成“出发 / 行进 / 停留”三个场景下每层穿着或背包里备着。
  规则在 `lib/data/weather/layering.dart`，阈值见下。
- **地图天气图**：降水、云量（模式预报，可播放 48 小时）；卫星云图（实况）；台风路径（日本气象厅）。

## 穿衣建议的规则（经验规则，可调）

体感取来源的体感温度，没有时用气温并说明；“怕冷 / 怕热”把判断用的体感平移 −3 / +3 ℃，显示仍为原值。

- 出发 = 起点体感；行进 = 沿途体感中位数；停留 = 沿途最冷处（山顶、垭口、午饭、等人）。
- 排汗层（全程穿）：最高体感 ≥ 22 且行进 ≥ 16 → 短袖速干；行进 ≥ 8 → 长袖速干；否则保暖排汗长袖。不穿棉。
- 保暖层按停留体感：≥ 18 不需要；12–18 薄抓绒；5–12 抓绒衣；−5–5 薄羽绒或厚抓绒；< −5 厚羽绒。
  出发体感 < 5 时出发穿着，行进体感 < −3 时行进也穿，停留时都穿。
- 防护层：降水概率 ≥ 40%、沿途降水 ≥ 0.5 mm 或有降水天气 → 防水硬壳；否则阵风 ≥ 10.8 m/s → 软壳或防风外套；
  阵风 ≥ 5.5 m/s 且停留体感 < 15 → 轻薄防风衣。
- 配件：紫外线 ≥ 3 防晒霜与遮阳帽，≥ 6 或雪面反光加墨镜；停留体感 ≤ 5 保暖帽与手套（≤ −8 厚手套）；
  阵风 ≥ 13.9 m/s 或停留体感 ≤ −5 头巾；日出前出发或日落后到达带头灯；降水较多带雨裤，有降水带背包防雨罩。
- 来源没有阵风、降水或紫外线时逐项说明“未评估”，不默认够用。冰爪等取决于路况的装备不由天气推断。
