## 简体中文

**名称**：山晴

**副标题**：徒步天气与行前规划

**短介绍**：出发前看天气，按线路查看沿途预报。支持导入徒步轨迹、比较天气来源，清楚了解数据时效与覆盖范围。

**推广文案**：导入你的徒步线路，选好出发时间，再看沿途气温、降水与风。山晴把预报来源、有效时次和缺失数据放在一起，让行前判断更有依据。

**完整介绍草案**：

山晴，帮你在出发前和徒步途中查看天气。

选择当前位置、地图上的任意地点，或导入自己的徒步线路，查看来源提供的天气预报。
不用注册账号，就能从示例线路开始体验。

- **沿着线路看天气**：查看沿途节点的气温、降水与风，核对不同位置、不同时间的预报。
- **按出发时间做准备**：查看固定时刻的天气，也可结合配速和爬升估算到达时间。预计到达时间会明确标为估算。
- **带上自己的轨迹**：导入 GPX、KML、KMZ 和 GeoJSON；也可以在地图上绘制线路。
- **比较来源，了解差异**：各天气来源独立展示，注明预报有效时间、获取时间、位置颗粒度与缺失项。
- **了解缓存状态**：已保存预报会标明更新时间，过期或更新失败时会提示。缓存只覆盖曾获取的时段，不能代替完整离线行程包。

山地天气可能与网格预报存在差异。请结合实际环境、当地官方预警与自己的经验决定行程。
当前应用未接入官方预警，也尚未提供完整离线行程包；出发前请另备可离线使用的地图与资料。

**关键词草案**：徒步,天气,登山,步道,路线,山地,逐时预报,行前规划,GPX
