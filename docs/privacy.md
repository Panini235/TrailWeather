# 隐私说明（面向用户）

## 我们收集什么

不收集。本 App 无账号系统、无后端服务器、无分析 SDK。

## 本地存储

设置、收藏与导入线路、业务缓存（线路/地图区域查询/天气）全部保存在设备本地
（shared_preferences），可在“设置 → 缓存与数据”逐项清除或导出。

- 节点图片：你从相册选择或拍摄的图片保存在应用文档目录（本机），只记录添加时所在节点的坐标与备注，不上传；
  卸载 App 会一并删除。图片本身可能带有拍摄设备写入的 EXIF 位置信息，分享原图前请自行留意。Web 端暂不保存图片。
- 天地图 Key 与自定义图源地址仅保存在本机；地图瓦片请求会把 Key 发给对应图源服务器。

## 离开设备的数据

为获取你请求的数据，以下最小必要信息会发送到对应公开服务：

| 场景 | 发送内容 | 接收方 |
| --- | --- | --- |
| 线路沿途天气 / 地图点位天气 | 采样节点或所选点坐标（约 4 位小数）、时间窗 | Open-Meteo / MET Norway / 已启用的其他天气来源 |
| 地图显示 | 瓦片坐标（标准地图行为） | 高德地图或 OpenStreetMap 瓦片服务 |
| 定位后的当地线路 / “搜索此区域” | 地图视野边界 | Overpass API（OSM） |
| 地点搜索 | 你输入的搜索词 | Open-Meteo Geocoding |
| 外部攻略与轨迹线索 | 你主动点击外部入口时的关键词和目标站点域名 | 百度网页搜索；随后访问的目标网站 |

- 混合搜索先在本机匹配已加载线路，并把关键词发送给地点搜索服务；只有你点击“小红书/两步路/六只脚”入口时，才在系统浏览器打开百度站点限定搜索。
- App 不抓取、解析、缓存或复制外部平台的搜索结果、账号 Cookie、攻略、图片和轨迹；外部网站的隐私政策由对应网站负责。

- 首页地图就绪后会请求一次前台定位权限；成功后移动地图、查询当前位置天气，并查询一次当前视野线路。
- 之后只在你点击“定位到我”时再次读取位置；不持续监听、不后台定位、不保存位置历史。
- 点击地图或地点搜索结果会把该点坐标发送给已启用天气来源；拒绝定位后仍可使用地图点选、地点搜索、线路和天气功能。

## 日志

- 应用日志不记录你的完整轨迹与精确位置。
- 数据源异常仅记录端点主机与 HTTP 状态码（SourceHttpException 设计）。

## 分享与导出提示

导出/分享线路时请注意内容可能包含住宅、常去出发点等敏感位置。

## 边界声明

- 本 App 的天气提示不能替代官方气象预警与户外安全判断。
- 缓存、导出和网络传输范围以本文件为准；如有变更将更新本页。
