# 隐私说明（面向用户）

## 我们收集什么

不收集。本 App 无账号系统、无后端服务器，不内置统计、广告或崩溃上报 SDK。

## 本地存储

设置、收藏与导入线路、业务缓存（线路/地图区域查询/天气）全部保存在设备本地
（shared_preferences），可在“设置 → 缓存与数据”逐项清除或导出。

- 节点图片：你从相册选择或拍摄的图片保存在应用文档目录（本机），只记录添加时所在节点的坐标与备注，不上传；
  卸载 App 会一并删除。图片本身可能带有拍摄设备写入的 EXIF 位置信息，分享原图前请自行留意。Web 端暂不保存图片。
- 天地图 Key 与自定义图源地址仅保存在本机；地图瓦片请求会把 Key 发给对应图源服务器。

## 首次启动同意

首次启动（以及隐私说明版本提升后）会进入引导页，展示摘要与“查看隐私说明”全文入口；
“我已阅读并同意隐私说明”默认不勾选，勾选后才能继续，未同意前不能返回关闭引导页。
同意前收到的外部轨迹文件只暂存，同意后再解析。同意记录为 `AppSettings.privacyAcceptedVersion`（本机）。
当前版本 2（2026-10-18，新增 AWS 高程瓦片请求）。
App 内全文见“设置 → 隐私说明”（`lib/ui/privacy/privacy_screen.dart`，文案在 `S.privacySections`），本文件与其保持一致。

## 离开设备的数据

为获取你请求的数据，以下最小必要信息会发送到对应公开服务：

| 场景 | 发送内容 | 接收方 |
| --- | --- | --- |
| 线路沿途天气 / 地图点位天气 | 采样节点或所选点坐标（约 4 位小数）、海拔（部分来源）、时间窗 | Open-Meteo / MET Norway；你自行配置 Key 后的和风天气、meteoblue |
| 海拔、空气质量 | 节点或所选点坐标 | Open-Meteo（elevation / air-quality） |
| 地图显示 | 瓦片坐标（标准地图行为）；天地图另含你填写的 Key | 所选底图服务商（高德、天地图、OpenStreetMap 等）或你自定义的图源 |
| 等高线、地形阴影、手绘海拔、3D 地形预览 | 高程瓦片坐标（与地图瓦片同类，可推知你在看的区域） | AWS（Terrain Tiles 开放数据，s3.amazonaws.com），仅在打开这些功能时 |
| “搜索此区域”线路 | 地图视野边界 | Overpass API（OSM），仅在你点击时 |
| 地点搜索 | 你输入的搜索词 | Open-Meteo Geocoding |
| 问题反馈 | 无自动发送；你点击后在浏览器打开 GitHub Issues，诊断信息需你手动粘贴 | GitHub |

- 这些服务按各自的隐私政策处理请求（包括 IP 地址）。
- App 不抓取、解析或缓存外部平台的搜索结果、Cookie、攻略、图片和轨迹。

## 位置

- 只在前台读取位置，不持续监听、不后台定位、不保存位置历史。
- 打开地图时，仅当此前已授权才自动定位一次（只检查权限，不弹系统授权框）；系统授权只在你点击“定位到我”时请求。
- 定位成功后查询该点天气（发送坐标给主天气来源）；不会自动查询 Overpass。
- 拒绝定位后仍可使用地图点选、地点搜索、线路和天气功能。

## 反馈诊断信息

“设置 → 问题反馈”生成的诊断信息只含构建地址、平台、已启用来源 id、底图 id、低耗电/海拔订正开关，
以及和风 Key 是否已配置（不含 Key 原文）；不含位置、线路或任何 Key。复制与提交都由你手动完成。

## 日志

- 应用日志不记录你的完整轨迹与精确位置。
- 数据源异常仅记录端点主机与 HTTP 状态码（SourceHttpException 设计）。

## 分享与导出提示

导出/分享线路时请注意内容可能包含住宅、常去出发点等敏感位置。

## 边界声明

- 本 App 的天气提示不能替代官方气象预警与户外安全判断。
- 缓存、导出和网络传输范围以本文件为准；如有变更将更新本页。
