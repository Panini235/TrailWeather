# 山晴使用文档

山晴是给徒步的人用的行前天气工具：导入一条线路，按出发时间看沿途每一段走到时的天气。
本文适用于 0.2.0 测试版。

## 安装

到 [Releases](https://github.com/Panini235/TrailWeather/releases) 下载对应平台的文件。

### Android

1. 下载 `shanqing-<版本>.apk`。
2. 打开安装包；系统提示“禁止安装未知应用”时，按提示允许当前浏览器或文件管理器安装。
3. 应用 ID 为 `app.shanqing.hiking`。签名证书指纹写在每个 Release 的说明里，可以用来核对安装包没有被替换。

以后的测试版直接覆盖安装，数据会保留。

### iOS（自签安装）

测试版没有上架 App Store，也没有 Apple 企业签名，提供的是**未签名的 IPA**
（`shanqing-<版本>-ios-unsigned.ipa`），需要用你自己的 Apple ID 签名后才能安装。
下面以 Windows / Mac 上的“爱思助手”为例。

> iOS 版目前只在 CI 上编译通过，还没有在 iPhone 真机上完整测试；“用山晴打开”外部文件在 iOS 上尚未接入，
> 请在 App 内用“导入线路”选择文件。

**准备**

- 电脑上安装爱思助手（官网 i4.cn），用数据线连接 iPhone，iPhone 上点“信任此电脑”并输入锁屏密码。
- 一个 Apple ID。签名时爱思助手会用它向苹果申请免费的开发证书，建议使用不常用的 Apple ID。

**第一步：开启开发者模式（iOS 16 及以上）**

1. iPhone 打开“设置 → 隐私与安全性”，拉到最下面，点“开发者模式”，打开开关。
2. 按提示重启手机；重启解锁后会弹窗询问是否打开开发者模式，点“打开”并输入锁屏密码。

如果“隐私与安全性”里找不到“开发者模式”：先完成第二、三步装上 App，选项就会出现，再回来打开。
iOS 15 及以下没有这一步。

**第二步：用爱思助手自签 IPA**

1. 爱思助手 →“工具箱”→“IPA 签名”。
2. 点“添加 IPA 文件”，选择下载的 `shanqing-<版本>-ios-unsigned.ipa`。
3. 选择“使用 Apple ID 签名”，添加你的 Apple ID（开启了双重认证的账号会要求输入验证码）。
4. 勾选当前连接的设备（爱思助手会自动读取设备 UDID），点“开始签名”，等待签名完成。

**第三步：安装**

签名完成后，在爱思助手“应用游戏”（或“我的设备 → 应用”）里点“导入安装”，选择签好名的 IPA；
也可以在签名完成的提示里直接安装。装好后桌面上会出现“山晴”。

**第四步：信任开发者**

第一次打开会提示“未受信任的开发者”。在 iPhone 上打开“设置 → 通用 → VPN 与设备管理”，
在“开发者 App”下点你的 Apple ID，点“信任”，再确认一次。之后就能正常打开。

**限制**

- 免费 Apple ID 签的 App **7 天后过期**，过期后打不开。重新签名、覆盖安装即可，App 里的数据会保留。
- 一个免费 Apple ID 同时最多给 3 个自签 App 签名。
- 爱思助手是第三方工具，不是山晴提供或认证的；签名与安装过程中输入的 Apple ID 由爱思助手处理。

## 快速开始

第一次打开会看到引导页，读完隐私说明后可以：

- **导入我的线路**：选择 GPX、KML、KMZ 或 GeoJSON 文件。
- **先看示例线路**：内置三条示例线路，带“演示”标签。

把线路带进来的其他方式：

- **用山晴打开**（Android）：在两步路、六只脚、奥维、微信或文件管理器里分享 / 打开轨迹文件，选“山晴”。
- **手绘**：首页“在地图上手绘线路”，点地图打点画线；拖动圆点改位置，拖线段中间的小点插入新点，点选圆点后可删除，
  右上角撤销（清空也能撤销）。底部实时显示距离、累计爬升 / 下降、估算用时和海拔剖面（海拔来自公开高程数据，取整到 10 m，
  只是估算）。默认叠加等高线和地形阴影，可以定位到自己的位置、标记营地和水源；完成后直接查天气，也能在“更多”里导出 GPX / KML。
- **地图发现**：地图页搜索地点、山峰或线路，或在地图上点任意位置查看该点附近的天气。

## 看懂线路详情

### 选择出发时间与来源

页面顶部两个按钮：

- **出发时间**：
  - *行程模式*：按出发时间和配速估算到达每个节点的时刻，看“我走到这里时可能是什么天气”；
  - *固定时刻*：整条线路看同一时刻的天气，“这个时候线路各处天气如何”。
- **天气来源**：默认 Open-Meteo；可以换成 ECMWF、MET Norway，或填了 Key 的和风天气、meteoblue。

### 线路摘要

最重要的提示放在最上面（例如“降水概率较高”“强风”），下面是最低 / 最高温、最大阵风和行程降水。
没有触发任何阈值时显示“当前数据未触发任何阈值提示（这不代表安全）”。
“比较出发窗口”可以对比未来几天不同出发时间的情况。

### 海拔剖面与沿途天气

剖面图上的圆点是天气节点，图标表示该节点的天气提示；线段颜色标出哪一段有风雨。
下方小地图可以全屏查看、切换图层（也能打开等高线和地形阴影）；“反向行走”按反方向重新估算。

小地图右下角的立方体按钮打开 **3D 地形预览**：单指拖动旋转、俯仰，双指缩放、平移、扭转，双击复位。
线路贴着地形画，被山体挡住的路段画成虚线。高程默认不放大，可以选 ×1.5 / ×2 看清起伏，画面右上角始终标着当前倍数。
地形来自公开高程数据（约 30 m 网格），只用来看山形，不是测绘成果，也不显示天气。

### 穿衣建议（洋葱法）

按出发、行进、停留三个场景给出每一层（排汗层、保暖层、外壳、裤子）是**穿着**还是**放背包**，以及配件
（头巾、手套、防雨罩、遮阳……）。右上角可选“怕冷 / 适中 / 怕热”。点“依据”可以看温度阈值和计算方法。
这是按预报温度、风、降水给出的通用建议，请结合自己的经验和装备调整。

### 节点详情

点任意节点的“节点详情”：

- **到达时的天气**：气温 / 体感、阵风（和持续风速分开）、降水量与概率、天气现象。
- **需要留意**：只有达到阈值才出现，例如紫外线偏强、接近 0℃ 层、低云、湿冷。
- **24 小时气象图**：云（低 / 中 / 高）、气温与体感、降水量与概率、风向（颜色看阵风）、紫外线叠在一张图上；
  默认停在到达时刻，点图上其他位置看那个小时。
- **同一地点不同海拔**：同一位置不同海拔的气温和风，帮助判断山顶与山脚的差别（按模式统计降尺度估算，非实测）。
- **空气质量**：区域级数值，山脊在逆温层之上时实际空气可能明显好于此值。
- **更多指标**：湿度、露点、云量、雪深等参考数据收在这里。

## 地图与天气图

地图页右侧的云朵按钮打开**天气图**，底部面板切换四种模式：

| 模式 | 是什么 | 说明 |
| --- | --- | --- |
| 降水 | Open-Meteo 模式预报 | 未来 48 小时，每小时一张；颜色为前一小时降水量（mm）。不是雷达实况。 |
| 云量 | Open-Meteo 模式预报 | 可分别看全部 / 低云 / 中云 / 高云。 |
| 卫星云图 | Himawari-9 红外（实况） | 最近 2 小时，约 10 分钟一张，有 20–40 分钟延迟；越亮越冷，代表云顶越高。打开时一次下载全部 13 张，约 5–10 MB 流量。 |
| 台风 | 日本气象厅 | 实况、过去路径与预报路径；虚线圆是中心落点的 70% 概率圆，不是风圈；风速为 10 分钟平均。 |

- 点播放按钮连续播放，拖动时间轴可以来回看。播放和拖动时，两个整点（或两张云图）之间是线性过渡，
  只为画面连贯；停下后显示的是整点预报 / 真实观测时刻。
- 降水和云量需要放大到省市范围才显示；拖动地图时不请求，停下后才按新范围获取。
- 右下角“ⓘ”有完整的数据说明。

地图右侧的图层按钮可以切换底图（高德、天地图、OpenStreetMap、OpenTopoMap 等）。
图层面板里的“地形”可以打开**等高线**和**地形阴影**：由公开高程数据在手机上计算，叠在任意底图上（包括高德、天地图）。
等高线放大到 10 级以上才显示，等高距 25–200 m 随缩放变化，左下角标着当前等高距；地形阴影只压暗背光坡，一眼看出山形。

## 离线行程包与分享

- **离线行程包**：在线路详情右上角点下载，保存线路与当前预报；没有信号时从首页“离线行程包”打开。
  离线底图尚未提供，请另备离线地图。
- **分享图片**：线路详情右上角的分享按钮，支持长图 / 简图 / 横图三种版式，图片里带下载二维码。

## 设置

- **显示与使用**：英制单位、风速单位（km/h、m/s、mph）、主题、出发窗口阈值、低耗电模式。
- **地图图层**：底图与叠加图层，可添加自定义瓦片源。
- **天气来源与密钥**：选择默认来源；填写和风天气、meteoblue、天地图的 Key（只保存在本机）。
  meteoblue 按次计费，只在你点击时查询。
- **数据与帮助**：使用指引、数据授权与署名、导出我的线路数据、问题反馈。

## 数据怎么读

- 所有天气都是**预报，不是实测**；网格预报代表一片区域，不是你脚下那个点。
- 提示按公开阈值计算，**不是官方预警，也不是安全评分**；官方预警尚未接入。
- 缺失的数据显示“此来源未提供”，不会当成 0；超出来源预报范围的时段显示“无数据”。
- 降水量（mm）和降水概率（%）是两回事；阵风和持续风速也是两回事。
- 到达时刻按配速估算，海拔修正、不同海拔的数值也是估算，都会标注。
- 详细说明见 [数据来源与授权](data-sources.md) 与 [数据分级](data-hierarchy.md)。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 地图瓦片不显示 | 默认高德瓦片（大陆直连）；在海外网络下可在“地图图层”切换为 OpenStreetMap。 |
| 高德瓦片在某个缩放级别一直空白 | 高德偶尔会返回空白图。新版本不再缓存这类空白瓦片，重新打开页面会重新加载；仍然空白时可清除应用数据。 |
| 和风天气显示“未配置” | 在“设置 → 数据源密钥”填入和风 API Host 与 Key（dev.qweather.com 可免费注册）。 |
| 天气图一直在加载 | 网络较慢时 Open-Meteo 可能需要几秒到十几秒；拖动地图后会重新获取。 |
| 某个来源显示“此来源未提供” | 该来源没有这个变量或这个时段，不是 0。可以换一个来源对比。 |
| Android 定位无权限 | 首页会请求一次前台定位；拒绝后仍可点选地图查天气。永久拒绝可点“打开设置”。 |
| iOS 打不开、闪退 | 自签 7 天过期，重新签名安装即可；或检查是否已在“VPN 与设备管理”里信任。 |
| 发现问题怎么反馈 | “设置 → 问题反馈”复制诊断信息，到 [GitHub Issues](https://github.com/Panini235/TrailWeather/issues) 提交。 |
