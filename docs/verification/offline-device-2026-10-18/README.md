## 发现的问题

1. **“用山晴打开”先出现 GoRouter 英文错误页（T-194，P1）**：冷启动和运行中两种情况都能复现，file:// 和 content:// 都会触发。屏幕显示
   `Page Not Found / GoException: no routes for location: content://media/external/file/…`，点 “Go to home page” 后导入确认框才出现，导入本身可以正常完成。
   原因是 Flutter 默认深链处理把 VIEW intent 的 data URI 当成路由交给了 GoRouter。证据：26。
2. **固定时刻包的前 8 小时永远缺失（T-195，P2）**：固定模式的包从本地 00:00 开始，但 Open-Meteo 以 `timezone=UTC` 请求，数据从 UTC 当天 00:00（北京时间 08:00）开始。
   24h/48h 包因此缺 7 节点 × 8 小时 = 56 个节点小时，ecmwf 包缺 5 × 8 = 40 个。缺口如实标注，不违反真实性，但“覆盖不全”会一直亮着。证据：08。
3. 小问题：ecmwf 包里露点显示为 “-0°C”（20），疑为四舍五入后的负零格式。
