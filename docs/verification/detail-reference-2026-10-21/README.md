# 截图版式恢复与重要天气标记（2026-10-21）

## 改动

恢复用户指定顺序：紧凑摘要→干净剖面及选中节点→原衣物动画→地图。偏好、三种场景、依据直接可用。剖面以小圆点呈现，选中节点说明/列表仍有编号；保留淡色海拔网格、距离刻度、读屏节点语义、地图单指平移/菜单和之前3D方向修复。未触发阈值仍为中性信息图标。

摘要突出降水/阵风数值，图下增加两项紧凑标签。分别比较各节点所选时段的实际降水量、阵风；有明确位置时可点击标签选中对应节点，并复用地图/列表联动。降水不求和、不写未经确认的mm/h，不用概率或持续风替代缺失量。零值/全同/全缺失不虚构特殊位置；并列峰值标注多处，部分节点缺失提示。风险颜色仅复用原有阈值。

## 方案复核及裤装建议

[三CLI结果](votes.json)：Gemini 3.8 Flash、DeepSeek v4.1 Flash、GLM5.3独立按通用说明投票，布局A=3、裤装建议A=3，遵循少数服从多数。均经7897代理，localhost NO_PROXY；未发送参考原图、私有线路或密钥。此为方案复核，不等于三位进行了设备测试。

裤装建议为**后续提案**：全身图示，上身/下身/背包分组；速干或软壳裤、保暖下装、防水硬壳裤；保暖打底与加绒外裤避免默认重复叠穿，硬壳区分穿着与备用。现有规则已有下装及雨裤文字，本批未新增裤装规则、未增加下身动画。分层的排湿/保暖/防护功能参考 [REI Layering Basics](https://www.rei.com/learn/expert-advice/layering-basics.html)；具体裤装规则不能只按单一气温决定，缺失风雨信息仍应明确不足。
