# 产品定义

## 一句话

像“地图找房”一样找徒步线路，但展示的是线路沿途、按你出发时间推演的多来源天气。

## 目标用户与场景

- 徒步爱好者：选线时想知道“明天上午这条线各路段什么天气”“我按 8 点出发走到垭口时几点、天气如何”。
- 痛点：城市天气 App 无法回答山路点位问题；把城市级数据渲染成看似精细的路段天气是欺骗。

## 核心闭环（首版必须）

地图浏览 → 点击/搜索线路 → 线路详情（轨迹/里程/爬升/海拔剖面）→
选日期与时刻（固定时刻模式）或出发时间+配速（行程模式）→ 沿途节点天气 →
切换/对比来源（含颗粒度与模型重叠说明）→ 收藏或导入自己的线路。

## 非目标（首版明确不做）

- 账号、社交、支付（不因商业化推迟地图天气闭环）。
- 完整离线路由引擎/导航。
- 轨迹记录（未来若做须显式开启并说明耗电）。
- “安全分数”类黑箱评分；官方预警接入。

## 体验要点

- 户外可读：高对比、深浅色、单手可达（底部面板/大点击区）。
- 空态/加载/限流/失败/离线/过期（stale）全状态覆盖，失败时如实展示，不静默。
- 演示数据永久标注“演示”。
- 时间滑块拖动只预览已加载数据，松手才请求（省电省配额）。

## 页面清单（已实现 v0.1）

1. 地图首页：OSM 底图 + 本地/示例/收藏线路渲染 + “搜索此区域”（Overpass）+ 地点搜索 +
   定位（按需）+ 线路列表抽屉 + 选中底部卡。
2. 线路详情：小地图（轨迹+节点）+ 事实卡 + 时间控制（双模式/日期/时刻滑块/配速面板）+
   来源 chips + 节点列表（点击选节点，长按开对比）+ 海拔剖面 + 摘要卡 + 风险提示卡 +
   来源透明卡（完整溯源弹窗）。
3. 节点对比面板：每来源独立卡片、缺失值、时刻对齐差值、颗粒度声明。
4. 设置：单位/主题/来源开关（含能力对照）/低耗电/采样间距/缓存管理/授权署名/隐私/导出。
5. 导入：GPX/GeoJSON 文件或粘贴，校验与限制，确认摘要（含敏感位置提示）后入收藏。
