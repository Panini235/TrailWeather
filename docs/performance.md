## 已实现的性能纪律（代码级）

- 渲染几何 DP 简化（zoom≥14 用 15m 容差，否则 40m）；里程/采样/ETA 用原始几何。
- 大轨迹解析与采样均为 O(n) 单次遍历；5000 点上限（导入限制）。
- 时钟仅在前台每分钟检查；跨小时或达到刷新间隔时更新时效状态，后台停表。按次计费来源与离线包联网更新仍由用户主动触发；耗电效果待真机验证。
- 请求：近似网格去重 + 分批 + 最小间隔 + 429/5xx 指数退避 + 缓存（TTL/SWR）。
- 地图拖动零天气请求；“搜索此区域”仅按钮触发且 bbox 限制 + 10min 缓存。

## 30 分钟耗电测试协议（待执行）

1. 设备：指定型号、系统版本、50% 电量、飞行模式关闭、固定 Wi-Fi、屏幕亮度 50%、
   省电模式关闭；记录构建模式（release）。
2. 剧本：打开 App → 地图浏览 10 分钟（每分钟拖动/缩放 2 次）→ 进入示例线路详情 →
   固定时刻滑块浏览 5 分钟 → 行程模式调整配速 5 分钟 → 对比面板打开 5 分钟 →
   返回地图再浏览 5 分钟。
3. 记录：耗电百分比（`adb shell dumpsys batterystats` 前后差）、请求数
   （来源方配额页/抓包）、平均帧率与慢帧比例（DevTools）。
4. 对照组：同剧本低耗电模式各跑一次。

**当前状态：无真机，全部标记未验证；不引用任何编造的耗电百分比。**
